📱 PokéScan - Politique de Confidentialité

Dernière mise à jour : 25 février 2026

Résumé : PokéScan respecte votre vie privée. Nous ne collectons, ne stockons et ne partageons AUCUNE donnée personnelle. Vos photos de cartes sont traitées temporairement puis immédiatement supprimées.

1. Éditeur de l'Application

Nom : Waphos
Application : PokéScan - Card Price Checker
Type : Application mobile Android

2. Données Collectées

PokéScan est conçu pour protéger votre vie privée. Voici les données traitées :

  • Photos de cartes Pokémon : Capturées via l'appareil photo de votre appareil uniquement pour identifier la carte.
  • Aucune donnée personnelle : Nous ne collectons ni nom, ni email, ni localisation, ni données de navigation.
  • Aucun compte utilisateur : L'application fonctionne sans inscription.

3. Utilisation des Données

Les photos de cartes sont utilisées exclusivement pour :

  • Reconnaissance de carte : Identification du nom et du numéro de la carte via OCR (reconnaissance optique) ou intelligence artificielle.
  • Redirection vers Cardmarket.com : Une fois la carte identifiée, l'application ouvre le site Cardmarket dans votre navigateur pour consulter les prix.

Traitement temporaire uniquement : Les images sont analysées en temps réel et immédiatement supprimées. Aucun stockage permanent n'est effectué sur nos serveurs ou sur votre appareil.

4. Partage des Données

  • API de reconnaissance d'images (Railway.app) : Les photos sont envoyées temporairement à notre serveur hébergé sur Railway pour analyse par intelligence artificielle. Les images sont supprimées immédiatement après traitement (< 10 secondes).
  • Cardmarket.com : L'application redirige vers le site tiers Cardmarket.com. Nous ne partageons aucune donnée avec Cardmarket. La navigation sur leur site est soumise à leur propre politique de confidentialité.
  • Aucun partenaire commercial : Nous ne vendons ni ne partageons vos données avec des tiers à des fins marketing.

5. Permissions Requises

L'application demande les permissions suivantes :

  • 📷 Appareil photo : Nécessaire pour scanner les cartes Pokémon.
  • 🌐 Accès Internet : Utilisé pour envoyer les images à l'API de reconnaissance et ouvrir Cardmarket dans le navigateur.

Vous pouvez refuser ces permissions, mais l'application ne pourra pas fonctionner sans accès à l'appareil photo.

6. Sécurité des Données

  • Chiffrement HTTPS : Toutes les communications entre l'application et notre serveur sont chiffrées.
  • Pas de base de données utilisateur : Nous ne stockons aucune donnée dans une base de données permanente.
  • Images non conservées : Les photos sont supprimées automatiquement après analyse (durée de vie < 10 secondes).

7. Cookies et Trackers

Aucun cookie, aucun tracker publicitaire. L'application ne contient pas de publicité et ne suit pas votre activité.

8. Droits des Utilisateurs (RGPD)

Conformément au Règlement Général sur la Protection des Données (RGPD), vous disposez des droits suivants :

  • Droit d'accès : Vous pouvez demander quelles données nous détenons (spoiler : aucune).
  • Droit de suppression : Les données sont déjà automatiquement supprimées après traitement.
  • Droit d'opposition : Vous pouvez désinstaller l'application à tout moment.

Pour exercer vos droits, contactez-nous (voir section Contact ci-dessous).

9. Utilisation par des Mineurs

PokéScan peut être utilisé par des mineurs sous la supervision d'un parent ou tuteur. Aucune donnée personnelle n'est collectée, l'application est sécurisée pour tous les âges.

10. Services Tiers

  • Railway.app : Hébergement de notre API de reconnaissance d'images. Politique de confidentialité Railway.
  • Cardmarket.com : Site tiers vers lequel l'application redirige. Politique de confidentialité Cardmarket.

Waphos n'est pas affilié à Cardmarket ou The Pokémon Company.

11. Modifications de cette Politique

Nous nous réservons le droit de modifier cette politique de confidentialité. En cas de changement important, la date de mise à jour sera modifiée en haut de cette page. Nous vous recommandons de consulter régulièrement cette page.

12. Conformité Légale

  • RGPD (Europe) : Conforme au Règlement Général sur la Protection des Données.
  • Google Play Policies : Respecte les règles de confidentialité de Google Play.
